# Operational runbook

1. Build VST3/AU on target OS.
2. Run pluginval.
3. Install VST3.
4. Install packaged Ableton Extension on supported Live beta.
5. Open Live and insert the plugin.
6. Configure provider key/model.
7. Scan library.
8. Ask for a complete track.
9. Inspect the plan.
10. Execute.
11. Render/resample.
12. Analyze.
13. Apply mix/master changes.
14. Save a versioned Set.

Never give the agent permission to delete or overwrite a Set without a user-controlled confirmation policy.
